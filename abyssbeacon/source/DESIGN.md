# 《深蓝信标》设计计划（Abyss Beacon）

> 一艘微型深潜器，一片被荧光生物照亮的失落海域。收集散落的光囊，送回三座熄灭的远古灯塔，让航路从迷雾里重新显形。原创世界观，不复用参考作品的 IP、命名与素材。

## 第一遍：Token 系统

### 主题与受众

- **主题**：深海探索 / collect-and-deliver。核心情绪是「孤独但温柔的深」——不是恐怖深渊，是水母与沉船构成的静谧花园。
- **受众**：Toy 平台休闲玩家，手机横屏 + 桌面双端。操作门槛要低（无倒计时、可慢逛），但收集与送达要有目标感。
- **首要任务**：收够光囊 → 送到灯塔 → 点亮航路。

### 配色（颜色即语义，不是装饰）

| Token | Hex | 角色 | 语义 |
|---|---|---|---|
| `--abyss` | `#05121f` | 深渊墨蓝 | 主背景、远景雾 |
| `--mid` | `#0b2b3d` | 中层海水 | 地形、体积光 |
| `--cyan` | `#4ff5d8` | 冷青荧光 | 光囊、安全、可收集 |
| `--magenta` | `#ff5c8a` | 洋红荧光 | 未知生物、 Territorial 警示 |
| `--amber` | `#ffc66b` | 琥珀暖光 | 灯塔、目标、进度 |
| `--foam` | `#dff5f0` | 泡沫白 | 正文、数字 |

关键决策：**三种荧光各自承载信息**，不是把画面刷成一片赛博绿。冷青=可拿，洋红=别碰，琥珀=要去。玩家不看文字只看颜色就能读懂海域。

### 字体（两套，各司其职）

- **标题 / 品牌**：极简无衬线，`font-weight: 800`，`letter-spacing: .18em`，全大写英文 `ABYSS BEACON`。不用衬线——衬线自带陆地/古典气质，与深海无关。
- **HUD 数字 / 仪表**：等宽 `ui-monospace, "SF Mono", Consolas`，`font-variant-numeric: tabular-nums`。像潜水表盘，数字跳动时不抖动。
- **中文**：系统黑体（PingFang / Microsoft YaHei / Noto Sans CJK），正文 `font-weight: 500`。

字阶：品牌 42px / 区块标题 13px（大写拉字距）/ 仪表数字 22px / 正文 13px / 微标 10px。行宽控制在 46 字符内。

### 版式

**原则**：UI 悬浮不贴框。不做玻璃卡片、不做描边面板——信息像浮游生物一样漂在深海里，只留细线、刻度与微光。画面正中央永远留给海与灯塔。

**标题页线框**（对齐：品牌左对齐于 8vw，主行动按钮左对齐同基线；右侧仅留一条竖排版本号）：

```
┌──────────────────────────────────────────────┐
│  ·  深海的灯灭了。                             │
│                                              │
│  ABYSS  BEACON          ◌ 光囊  0 / 12        │  ← 品牌左对齐
│  深 蓝 信 标             ◌ 灯塔  0 / 3         │  ← 副数据同列
│  ─────────────                                │
│  驾驶深潜器，收集光囊，                        │
│  送回熄灭的远古灯塔。                          │  ← 行宽 < 46
│                                              │
│  [ 下 潜 ]  →                                 │  ← 唯一主行动
│                                              │
│                                    v1.0.0 ↑   │  ← 竖排版本号
└──────────────────────────────────────────────┘
        背景：缓慢漂移的荧光海 + 远处一点琥珀光
```

**游戏 HUD 线框**（对齐：所有仪表贴安全区内缘，中心 60% 区域不放任何 UI）：

```
┌──────────────────────────────────────────────┐
│ ⌖ DEPTH  042 m      │        光囊  07 / 12 ◌ │
│ ◇ 航向  NE          │        灯塔  01 / 03 ◇  │  ← 顶栏两角，细线分隔
│                                              │
│                  [ 海域中心 ]                  │
│              ~ 水母 · 沉船 · 灯塔 ~            │  ← 中心留白给画面
│                                              │
│                  ◈ 靠近灯塔 · 按 E 投放        │  ← 唯一情境提示，居中下方
│                                              │
│  ╔══╗                                  ╔══╗   │
│  ║WAS║  移动 · 上浮/下潜              ║ C║   │  ← 触屏按键（仅触摸端）
│  ╚══╝                                  ╚══╝   │
└──────────────────────────────────────────────┘
```

- 顶栏：`padding: env(safe-area-inset-top)` 起算，两角对齐，中间 1px 分隔线。
- 触屏区：左右下角，全部 `env(safe-area-inset-*)` 内缩；矮视口（≤480px 高）按键收紧到 52px。
- 情境提示：出现时淡入，持续 3s 后淡出，不常驻。

### 原则

1. **一处用力**：灯塔点亮瞬间的光柱与琥珀扩散，是全场唯一的"高潮特效"；其余时刻安静克制。
2. **颜色即信息**：玩家不看 HUD 也能靠三色荧光读懂海域。
3. **中心留白**：任何 UI 不侵占画面中央 60%。
4. **触屏是一等公民**：控件、safe-area、矮视口从第一行代码就存在，不做事后补丁。
5. **非触发动效极简**：入场一次编排好的下潜镜头；水母与浮游生物的环境运动是缓慢的、非"满屏 hover"。

## 第二遍：对照 brief 自检

| 套路化默认 | 本方案是否踩坑 | 证据 |
|---|---|---|
| 近黑底 + 荧光绿（赛博朋克默认） | ❌ 未踩 | 三色语义荧光（青/洋红/琥珀）分工，主色不是绿；背景是墨蓝非纯黑 |
| 玻璃卡片 HUD / SaaS 圆角套件 | ❌ 未踩 | 仪表只有细线与文字，无卡片无描边面板 |
| 编号 01/02/03 + 全大写标签 + 单字高亮 | ❌ 未踩 | 无编号体系；大写仅用于品牌与仪表字段名（功能性），标签用中文动宾 |
| 暖奶油底 + 衬线大标题 | ❌ 未踩 | 无衬线、无奶油色 |
| 报纸式细线分栏 | ❌ 未踩 | 细线仅作仪表分隔，不做分栏排版 |
| 电影黑边（复用海风竞速的视觉签名） | ❌ 未踩 | 全屏无黑边，避免自我重复 |
| 照搬参考的青绿+蒸汽朋克写实 | ❌ 未踩 | 低多边形程序化重绘，生物荧光语言原创；无 IP、无素材复用 |
| 事后补触屏检测（夜行记录仪的坑） | ❌ 未踩 | IS_TOUCH 三分判定 + pointer 通道 + body.touch 从第一行代码落地；标题页开始按钮纳入视口断言 |

**相对独特性结论**：配色、字体角色、版式留白规则均从「深海探索 + 生物荧光」这一主题长出，且刻意避开了本人前作（海风竞速的电影黑边、夜行记录仪的界面语言）与参考作品的写实蒸汽朋克。可以开工。
