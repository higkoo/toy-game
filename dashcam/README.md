# 夜行记录仪 · Night Dashcam

第一人称深夜货运模拟。你是平台上一名货车司机，开着一台 2.0L 自然吸气气缸的四驱小卡在雨夜的公路上跑长途，一边开车一边直播。

零第三方库、零网络请求的纯静态页面：**43 个模块、18183 行自研 WebGL2 引擎**，从路面生成、车辆物理、后视镜、雨刮、玻璃裂纹到收音机里的电台，全部自绘。

## 玩法

- **开播**：在「开播」页选车、点「开始直播」进入驾驶室，拧钥匙点火后起步。
- **跑长途**：路上有测速、罚单、抛锚、扣车、追捕。按 `Q` / `E` 切换页签，`Enter` 开始直播或购买座驾，方向键在车库页换车。
- **经营**：直播有观众、有收益，余额进账；事故、罚单、抛锚都会扣钱。车库页可以买更好的车。
- **存档**：设置页可导出 / 导入 JSON 存档，也可以重置。

## 排行榜

设置页右下角的版本号 `v103` 是一枚**隐藏入口**：点它（或键盘 Tab 到它按 Enter）打开累计里程榜。

沿用三纪 / 四号泊位的做法——页面不主动提示，属于彩蛋；入口外观与周围文字完全一致（无边框 / 底色 / 下划线 / tooltip），只有悬停变色和 `:focus-visible` 焦点圈给线索，Esc 关闭后焦点归还入口。

榜单用 `BOARD = 1`（每个 Toy 有自己独立的 5 个榜位，不会和其它游戏串榜）。计分口径与项目其余游戏一致：

- 分数 = **累计总里程（公里，取整）**
- 跨局累计，**只增不减**
- `submitScore` 传绝对分，服务端只保留历史最高分
- 每次跑完一局结算时由游戏内部 `Profile.applyRun()` 上报，不侵入 43 个模块的引擎逻辑

面板由页面自绘，用游戏自己的暗底 `rgba(9,11,15,.94)` 与直播红 `#e8262b`；分总榜 / 本周两个榜期，点开才拉一次并缓存，不轮询。

## 依赖

游戏本体**零第三方网络依赖、零外部资源引用**，断网可玩。唯一的平台能力是排行榜：`index.html` 用 `defer` 加载 Toy 平台 SDK（`s1.hdslb.com`），加载失败只影响榜单面板，不影响游戏本体；非 Toy 宿主里打开面板会提示「到 B站 App 内打开本 Toy 再试」并提供「重试」。

BGM 是预渲染的 base64 Ogg Opus（84 BPM），随包分发，不请求网络。

### 为什么拆包

单文件版有 3.15 MB，超过 Toy 入口 `index.html` 解压后 1 MB 的上限。拆成 `index.html`（约 147 KB）+ `app.js`（约 2.85 MB）后，入口回到限制以内，游戏代码本身不需要任何构建工具或压缩处理。

单文件原始版仍保留在工作区，作为可分享的单文件产物；它的内联代码与 `src/app.js` 逐字节一致。

## 移动端判定

原代码里 `MOBILE` 是一个**构建期常量**（`const MOBILE = false;`），移动端相关的 14 个模块虽然完整存在但默认被关闭。现在改成**运行时判定**：

```js
const MOBILE = (function () {
  var q = (location.search || '') + (location.hash || '');
  if (/[?&]mobile=1/.test(q)) return true;
  if (/[?&]mobile=0/.test(q)) return false;
  var touch = ('ontouchstart' in window) || (navigator.maxTouchPoints > 0);
  var fine = !!(window.matchMedia && window.matchMedia('(pointer: fine)').matches);
  return touch && !fine;
})();
```

判定顺序：URL 强制 > 触屏且非精确指针（鼠标 / 触控板）。这样手机进 Toy 自动得到触屏控件 + 横屏保护，桌面进 Toy 保留键鼠与完整仪表。

调试用的开关：`?mobile=1` 强制移动端，`?mobile=0` 强制桌面端。

## 发布到 Toy

以 `src` 目录作为页面根目录上传，`assets` 里的 icon / poster 作为外层素材：

```bash
toy create src \
  --title "夜行记录仪" \
  --slug dashcam \
  --category GAME \
  --theme dark \
  --icon assets/icon.png \
  --poster assets/poster.jpg \
  --yes
```

## 校验

- 4 个视口（桌面 1280×800、移动横屏 844×390、移动竖屏 390×844、`?mobile=1`）共 **80 项浏览器断言 0 失败**：移动端判定、竖屏保护遮罩、版本号入口隐形、键盘可达、点击开面板、面板文案与配色、Esc 关闭、焦点归还、里程取整上报且只增不减、无新增 JS 异常
- 静态一致性断言 12 项全过（包体与单文件版代码逐字节一致、`MOBILE` 运行时判定存在、上报点唯一）
- `node --check` 两个 JS 通过

### 已知边界

沙箱没有 GPU，WebGL2 场景无法真实渲染；上面的浏览器测试用一套最小 WebGL2 替身让 UI 层跑起来，验证的是交互与 DOM 逻辑，不等于真机画面已经过验。真实的 WebGL2 渲染、陀螺仪、AudioContext 解码与 App 内 SDK 握手仍需在 App 里确认。
