## 二、录屏方案（横屏）

1. **环境**：桌面 Chrome / Edge，窗口 1920×1080，打开 Toy 预览或线上链接，F11 全屏，缩放 100%。
   - 若用沙箱录屏助手，可直接用 Playwright 以 1920×1080 视口逐帧操作并录制（见下方「可复用录屏脚本」）。
2. **操作节奏**：滚动用滚轮分段慢滚，每段停 1–2 秒；点击前先把鼠标移到按钮上停留片刻，让观众看清位置。
3. **隐私**：留言内容请用脚本里给的示例句，不要填真实个人信息；不登录账号录屏，避免露出昵称头像。
4. **后期**：
   - 加旁白音轨，音量 -6dB左右，BGM -20dB 以下。
   - 关键公式、金句用大字幕强化（字号 ≥ 48px，白字 + 半透明黑底）。
   - 不要加花哨转场，用淡入淡出即可，符合肃穆基调。

### 可复用录屏脚本（Playwright，可选）

```python
# 需先 pip install playwright && playwright install chromium
import asyncio
from playwright.async_api import async_playwright

URL = "https://www.bilibili.com/toy/<你的 Toy 链接>"  # 发布后替换

async def main():
    async with async_playwright() as p:
        b = await p.chromium.launch(args=["--no-sandbox"])
        ctx = await b.new_context(viewport={"width": 1920, "height": 1080},
                                  record_video_dir="./video", record_video_size={"width": 1920, "height": 1080})
        page = await ctx.new_page()
        await page.goto(URL, wait_until="domcontentloaded")
        await page.wait_for_timeout(2500)
        # 序厅停留
        await page.wait_for_timeout(8000)
        # 分段下滚
        for y in (700, 1400, 2100, 2800):
            await page.evaluate(f"window.scrollTo({{top:{y},behavior:'smooth'}})")
            await page.wait_for_timeout(9000)
        # 献花
        for rid in ("principia", "euclid", "abacus"):
            await page.locator(f'[data-flower="{rid}"]').click()
            await page.wait_for_timeout(3000)
        # 悼念墙
        await page.locator("#msgText").fill("愿手算的笔迹，别被算法抹平。")
        await page.locator("#msgName").fill("一个还记得的人")
        await page.locator("#msgForm button[type=submit]").click()
        await page.wait_for_timeout(4000)
        # 悼词
        await page.locator('#relicList .relic[data-id="abacus"] h3').click()
        await page.locator("#genBtn").click()
        await page.wait_for_timeout(6000)
        await ctx.close(); await b.close()

asyncio.run(main())
```

> 录出来的视频是**无声**的，旁白与 BGM 需在剪辑软件里叠加。时长按脚本节奏调整到 1 分 20 秒以上。
