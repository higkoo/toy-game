# 数学界赛博葬礼 · 人类文明遗址数字悼念厅

一个放在 B 站 Toy 里的**互动悼念展厅**。设定为 2026 年 AI 接管了证明、作图、修图与计算，于是把那些曾经需要「人」亲手完成的手艺——公式、草稿、圆规、对数表、修图图层、算盘——送进一座赛博悼念厅。参观者可以为每件遗物献一束花、在悼念墙留言、生成一段悼词带走。

纯前端、零后端、零外部依赖（除官方 toy-sdk），所有留言与献花记录只保存在参观者自己的设备上。**内容为虚构设定，向所有手工技艺致意。**

## 页面结构

| 区块 | 内容 |
|------|------|
| 序厅 | 世界观说明 + 系统状态 + 向下参观引导 |
| 遗物陈列 | 六件遗物碑铭：公式、墓志铭、献花按钮；每件只记一次 |
| 悼念墙 | 留言表单（140 字 + 署名），本地保存，倒序展示 |
| 悼词生成器 | 点选一件遗物 → 生成悼词 → 复制带走 |
| 结语 | 收束文案 + 保管处落款 |

六件遗物：

1. 《自然哲学的数学原理》—— `F = G · m₁m₂ / r²`
2. 手算草稿 —— 算到小数点后很多位的年代
3. 《几何原本》与直尺圆规 —— 五条公设，一座大厦
4. 对数表 —— 把乘法变成加法
5. 古法 PS 修图 —— 一层一层地抠，一根一根地修
6. 算盘 —— 噼里啪啦响了一千年

## 交互与计分

- **献花**：每件遗物献花后按钮变「已献花」并禁用，同一件只记一次；花瓣飘落动效，`prefers-reduced-motion` 下自动关闭。
- **悼念墙**：留言存 `localStorage`（`memorial.msgs`，最多保留 50 条），只在本机可见，不上传。
- **悼词生成**：点击遗物卡片选中（避开按钮），按模板生成悼词；复制走 `navigator.clipboard`，失败回退到 `execCommand`。
- **排行榜**：原生 Toy 榜单，点右下角版本号打开。口径为「每处遗址献花 +1，同一处不重复计，一直累计」，取历史最高分。献花时调 `ToyRank.watch(id)`，用 `memorial.rank.v1.seen` 去重。
- **底栏适配**：按容器状态写入 `--toy-bottom-inset`，为 Toy 原生互动栏预留高度；Web 环境下等同系统安全区。

## 设计 token

- **配色**：近黑墨蓝 `#0b0f14` 打底，骨白 `#e8e2d5` 正文，悼念朱红 `#b4463a` 作唯一强调，电子青 `#5fd4c4` 只用在公式与「系统状态」冷光，暗金 `#8a7755` 用于墓志铭与署名。
- **字体**：衬线（Songti/Noto Serif CJK/Georgia）承担叙事与标题，等宽（Menlo/Consolas）承担公式、编号、系统提示与按钮，两套字阶分工明确。
- **版式**：单栏 760px、行宽受控；分区以细分隔线 + 编号标题组织；遗物卡片二列栅格（序号 / 正文）；全站克制，仅献花一处用动效。
