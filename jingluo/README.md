# 经络图谱 · 3D

3D 人体十四经脉学习图谱。人体、骨架、脏腑和经脉全部由 three.js 程序化生成，不依赖外部 3D 模型或贴图。

## 功能

- 十四经脉完整展示：十二正经 + 任脉 + 督脉，双侧经脉自动镜像。
- 161 个常用代表穴位，点选后查看编号、定位、主治与所属经脉循行。
- 拖拽旋转、滚轮 / 双指缩放、正背面与左右侧视角。
- 经脉筛选：只看一条经脉，再点一次恢复全身；足太阳膀胱经、督脉自动转到背面。
- 穴位搜索：支持中文名与编号，如“合谷”“LI4”。
- 聚焦穴位、上一穴 / 下一穴、随机一穴。
- 皮肤 / 骨骼 / 脏腑三层解剖显示，默认只开皮肤，突出经脉。
- 桌面与手机响应式；手机端穴位信息为底部抽屉。

## 数据范围

每条经脉选取常用代表穴位，共 161 个；不是 361 个经穴的全集。定位按经络腧穴常用体表定位整理，主治为学习向的概述，不构成诊断或治疗建议。

## 操作

| 操作 | 桌面 | 手机 |
| --- | --- | --- |
| 旋转 | 按住拖动 | 单指拖动 |
| 缩放 | 滚轮 / ＋－按钮 | 双指捏合 / ＋－按钮 |
| 查看穴位 | 点击发光点 | 点击发光点 |
| 筛选经脉 | 左侧列表 | 顶部横向列表 |

## 实现

- `src/index.html`：界面与样式。
- `src/data.js`：十四经脉坐标与穴位资料。
- `src/app.js`：three.js 场景、程序化人体、经脉曲线、屏幕空间点选与相机控制。
- `src/three.global.js`：three.js 全局构建（MIT License，Copyright 2010-2025 three.js authors）。

经脉线使用 `TubeGeometry` + `CatmullRomCurve3`；穴位点击不用射线打小球，而是把所有穴位投影到屏幕后取最近点，避免密集穴位误选。
