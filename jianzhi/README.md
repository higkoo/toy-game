# 我的健康减脂方法（jianzhi）

把腾讯文档《我的健康减脂方法》做成 B 站 Toy 内容站点。路径 `jianzhi`，参考 `sanji`、`benneng` 的技术形态，但视觉语言独立。

- 内容来源：[腾讯文档 · 我的健康减脂方法](https://docs.qq.com/doc/DQ09KZ1BuaGpaT0Fh)（真实 `file_id` 为 `COJgPnhjZOAa`）
- 作者原站：[我的开源减脂方案](https://higkoo.github.io/healthy/jz/100.html)
- 当前版本：`v1.1`（v1.0 首次创建；v1.1 随包体修正 Toy 外层展示主题为 `light`）
- 数据周期：2024.4.3 — 5.16，共 44 天、两期

## 一页设计计划

**主题与受众。** 这不是养生古籍，也不是健康 App，而是一份**个人身体测量记录**：体脂秤逐日读数、每日三餐、几十条营养问答。读者要么想马上知道「怎么吃」，要么想核对数据是不是真的。所以数字是主角，文字退后。

| Token | 值 | 角色 |
| --- | --- | --- |
| `--paper` | `#F2F1EA` | 冷灰记录纸底色（不是暖奶油） |
| `--white` | `#FBFAF6` | 曲线卡片、表格底，比纸亮一档 |
| `--ink` | `#1B2830` | 主文字，墨蓝黑而非纯黑 |
| `--ink-2` / `--ink-3` | `#4E6066` / `#6E7E81` | 正文 / 刻度标签两级弱墨 |
| `--rule` / `--rule-2` | `#CDD5D2` / `#AEBBB8` | 24px 坐标纸网格、分隔线 |
| `--red` | `#B8412C` | **唯一强调色**：体检单上圈数字的红笔 |

**字体。** 只用两个角色：等宽字族（`ui-monospace / SFMono / Menlo / Consolas`）承担所有数字、刻度、标签，开 `tabular-nums` 保证表格对齐；中文用系统黑体。刻意**不用衬线**——衬线是 `sanji` 的语言。首屏读数 `clamp(34px, 8.6vw, 68px)`，正文 14.5px / 1.85，行宽 ≤ 66ch。

**版式。** 24px 极淡坐标纸网格作骨架；桌面端左缘一条装订刻度尺；每章「左窄栏真实元数据（依据 / 3 条、执行 / 5:3:2、测量 / 44 天…）+ 右宽栏内容」两栏，760px 以下合并成一栏。分区靠横线与留白，不用卡片、不用阴影、不用圆角胶囊。

**一处用力。** 44 天体重曲线（朱红实线 + 极淡面积 + 4.24 第二期分界竖线），用真实数据画，一次入场动画，尊重 `prefers-reduced-motion`。其余安静：五三二比例条是内容本身不是装饰，问答用原生 `<details>`。

**两遍自检（对照 brief）。**

| 常见默认 | 本页的取舍 |
| --- | --- |
| 暖奶油底 + 衬线大标题 + 陶土色 | 冷灰纸 + 无衬线 + 墨蓝黑，朱红只给数据 |
| 健康类绿白 + 圆润卡片 + 叶子图标 | 完全避开绿色，零卡片、零图标 |
| 近黑底 + 荧光绿 | 不用 |
| 报纸式细线多栏 | 一栏正文 + 左栏元数据，来自记录表而非报栏 |
| `01/02/03` 编号、全大写标签 | 左栏改用真实内容元数据（单位、天数、条数） |
| 满屏 hover / 入场动效 | 只有曲线画一次；展开、搜索是响应动作 |

与 `sanji`（米黄宋体古籍）、`benneng`（深色人像）技术一致、视觉互不相同：三个内容站各有各的识别。brief 说「参考 sanji、benneng」按技术形态理解，视觉不复制。

`src/data/content.js` 由腾讯文档导出的语义化 HTML 程序化生成，**勿手工编辑**。生成脚本不入库，内容已固化。

| 数据 | 数量 | 说明 |
| --- | --- | --- |
| 核心思路 | 3 条（各 2 点） | 能量平衡 / 升糖速度 / 营养均衡 |
| 方法清单 | 6 + 5 + 3 条 | 饮食 / 饮水 / 睡眠 |
| 体脂逐日 | 44 天 × 9 项 | 一期 22 天 + 二期 23 天，`4.24` 在两期重复，合并去重 |
| 体脂截图 | 44 个外链 | 表格里点日期跳原站图片，不在 Toy 包内嵌图 |
| 饮食日志 | 44 天 × 三餐 | 5.1–5.3 原文是竖排单字，已拼回「劳动人民节日 / 劳动创造幸福 / 三天自由饮食」 |

## 技术约定

与仓库其余 Toy 一致，无构建步骤：

```text
jianzhi/
├── src/
│   ├── index.html          # 骨架；首屏关键事实静态写死，JS 挂了也不白屏
│   ├── css/app.css         # 全部样式（含 token、响应式、动效）
│   ├── js/app.js           # 渲染、曲线、问答搜索、章节计分、底栏适配
│   ├── js/rank.js          # TOY 榜单模块（项目 v3 派生的定制文案版）
│   ├── data/content.js     # 文档结构化数据
│   └── img/icon.png, poster.jpg
└── README.md
```

- **SDK**：`defer` 引入 `toy-sdk.js`（与 `benneng` 一致）；`ToyRank` 有就绪重试，面板读取带 3500ms 超时兜底。
- **底栏适配**：与 `sanji` / `benneng` 同一套 `--toy-bottom-inset` 探测逻辑，避开 TOY 原生互动栏遮挡；页脚、右下角版本号都用它。
- **榜单入口**：右下角版本号 `v1.1` 是原生 `<button>`（沿用三纪做法），键盘 Enter / Space 可打开，`:focus-visible` 有焦点圈。
- **计分**：`board: 1`，`kind: content`。`ToyRank.watch(id)` 按章节 id 去重，章节进入视口 72% 高度即记 1 分，首屏算一章 → 打开即 +1，全站最多 7 分。只加分、传绝对值、平台取历史最高分；面板点开拉一次并缓存，不轮询。
- **无障碍**：语义标签、`scope="col"` 表格、`aria-label` 曲线、`<noscript>` 提示、`prefers-reduced-motion`、375px 一栏布局、表格横向滚动。

## 发布

```bash
toy create jianzhi/src \
  --title "我的健康减脂方法" \
  --slug jianzhi \
  --category GUIDE \
  --theme light \
  --visibility public \
  --icon jianzhi/src/img/icon.png \
  --poster jianzhi/src/img/poster.jpg \
  --yes
```

> 首次 `create` 时实测 `--theme light` 未落到服务端（记录为 `dark`）；审核中的 Toy 不带包体改元数据会被拒（`307034`）。因此用带包体的 `toy update <id> jianzhi/src --theme light --yes` 修正，并同步把版本号 +1。浅色纸页面应配 `light` 外层主题。

之后更新用 `toy update <id> jianzhi/src --yes`，**每次版本号 +1**。

## 边界

- 「读过一章」按进入视口算，不判断是否读完；清缓存或换设备会重新计数，但平台历史最高分有天然防刷。
- 体脂截图是 `higkoo.github.io` 外链，Toy 包内不含这些图片。
- 页面是个人实践记录，不构成医学或营养建议（页脚与出处均已注明）。
