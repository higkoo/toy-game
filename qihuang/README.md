# 岐黄典籍故事 · 中医文化合集

一个放在 B 站 Toy 里的**中医文化 / 典籍故事**阅读合集。只谈典籍源流、名医典故、药名博物与天文历法，**不涉及任何诊疗内容**，仅供文化阅读。

## 为什么要重做

原《倪海厦学习天地》的知识库因含症状、方剂、剂量、穴位主治、药材功效等诊疗内容，被审核判定为「违法违规、其他」而反复驳回。对照实验证实：清空知识库数据后首页可正常过审，违规源就是知识库里的诊疗条目本身。

本版本保留已过审的首页框架与视频导航，把知识库整体改写为**零诊疗的文化读物**，并以新名称、新 slug 重新创建 Toy。

## 内容结构

### 首页
- 天纪 / 人纪 / 地纪：课程影像合集，App 内通过 `toy.navigate` 打开 B 站视频
- 电子书与资源包、知识库入口、榜单（右下角版本号）
- 全站标注「仅供文化阅读，不构成医疗建议」

### 知识库（`kb/`）
七册、88 则文化故事，每条含「正文 + 出处 + 体裁标签」，支持全文搜索、体裁筛选（典籍 / 人物 / 典故 / 风物）与章节导航：

| 册页 | 主题 | 则数 |
|------|------|------|
| `zhenjiu.html` | 针砭源流：器具、经络思想、针灸铜人、人物典故 | 11 |
| `neijing.html` | 内经与象数：成书、阴阳五行、天人相应、节气 | 13 |
| `bencao.html` | 本草博物：神农传说、三品分类、药名、博物与文献 | 13 |

## 合规原则

- **零诊疗**：不出现症状—方剂—剂量、穴位主治、药材功效、疗效宣称
- **零敏感药材**：不出现犀角、羚羊角、麝香、穿山甲、虎骨、熊胆等
- **零政治运动引用**：删除文革 / 大跃进等相关表述
- **外链不跳转**：讲义等第三方链接一律「点击弹出、手动复制粘贴访问」

## 生成与修改

知识库内容由 `gen_kb.py` 生成：编辑脚本里的条目数据后运行 `python3.11 gen_kb.py`，会重写 `src/kb/` 下的册页、总目录、`assets/kb.js` 并补充 CSS。

```bash
cd qihuang
python3.11 gen_kb.py
```

## 发布

```bash
toy create ./src \
  --title "岐黄典籍故事 · 中医文化合集" \
  --slug qihuang \
  --category COLLECTION \
  --theme light \
  --visibility public \
  --icon ./src/img/icon.png \
  --poster ./src/img/poster.jpg \
  --yes
```
