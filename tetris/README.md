# 小偶像方块

一款放在 B 站 Toy 里的俄罗斯方块小游戏，手机触屏和电脑键盘都能玩。

## 玩法

方块从顶部下落，堆满一行即可消行。消行越多得分越高，等级会逐渐提升，方块下落也会变快；堆到顶部则游戏结束。

- 显示下一个方块
- 显示落点影子，方便判断落位
- 最高分保存在本地
- 支持暂停、重新开始和全屏

## 操作

屏幕方向键：

- ← / →：左右移动
- ↑：顺时针旋转
- ↓：加速下落

键盘：

- `←` / `A`、`→` / `D`：左右移动
- `↓` / `S`：加速下落
- `↑` / `Z` / `W`：旋转
- `空格` / `Enter`：直接落底
- `P`：暂停
- `Esc`：退出全屏

右下角的 `⌨` 按钮可以在方向键布局和键盘提示布局之间切换。

## 说明

单机游戏，无需联机，也不依赖后端。核心玩法离线也能玩；Toy SDK 用于页面运行环境与原生排行榜（离线时不上报，联网打开面板会读到平台已有记录）。

## 榜单

页面接入 TOY SDK 原生排行榜，终端用户可点页脚「排行榜」查看总榜 / 本周榜、我的名次和 Top 20。

- **榜位**：`board: 1`。不同 Toy 天然隔离，每个作品各用一套榜单。
- **口径**：累计阶梯分，只加不减。一次消 1 / 2 / 3 / 4 行分别 +1 / +2 / +3 / +4，跨局一直累计；开局即保底 1 分，玩过就上榜。
- **与 HUD 的区别**：这里的「累计积分」是跨局累计的榜单分，HUD 里的「得分」是单局得分、「最高分」是本地单局最高纪录，三者互不相同。
- **上报**：`submitScore` 传绝对分，平台只保留历史最高分；失败按指数退避重试，不轮询。
- **面板**：点开时拉一次 `getRankList` + `getMyRank` 并缓存（总榜 / 本周各一份），带加载中、空态、失败重试和非 App 提示。

边界：单机游戏无法阻止改写本地存储刷分；「悔方块」回滚本局分数时不回滚榜单分（口径只加不减），重复消同一行可能重复计分。清缓存或换设备后，平台返回的历史最高分会在打开面板时校准本地显示。

当前源码版本：`v6`
