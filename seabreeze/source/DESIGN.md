# 《海风竞速 · Sea Breeze GP》设计计划

## 一句话

黄昏海岸线上的低多边形竞速——三圈环形赛道，漂移过弯，氮气加速，和七台 AI 车抢一个名次。

## 主题与受众

- **受众**：Toy 平台上的休闲玩家，手机横屏或桌面点击即玩，3 分钟能跑完一局。
- **主题来源**：不是「赛车游戏」的通用想象（条纹、轮胎墙、观众席），而是**傍晚的海滨公路**——落日把海面烧成橙金，路两侧是防风林、灯塔、白栏杆，路面被海风吹得发亮。
- **「唯一用力的一处」**：整个画面的主色是**落日暖金**（`#ffb547`），它既是 HUD 主色也是天光、是海面反光、是尾灯雾。冷色只出现在两个地方——天空渐变的顶部（`#1b2a4a`）和对手车的青绿（`#3fd0c9`），用来把暖色衬托出来。

## 配色（6 色，取自参考页 token）

| 名称 | 值 | 角色 |
| --- | --- | --- |
| `--sun` | `#ffb547` | 落日暖金：HUD 主色、天光、氮气条、海面高光 |
| `--sea` | `#3fd0c9` | 海与青绿：对手车、生命值、进度条 |
| `--deep` | `#16233d` | 深蓝：天空顶、路面暗部、面板底 |
| `--sand` | `#f0d9b5` | 沙色：沙丘、路肩、辅助文字 |
| `--ink` | `#f4f6fb` | 正文白：主标题、速度数字 |
| `--danger` | `#ff5a6e` | 危险红：对手车尾迹、碰撞警告、最后一圈 |

对比检查：`--ink` on `--deep` ≈ 13.8:1；`--deep` on `--sun` ≈ 8.1:1，均过 WCAG AA。

## 字体

- **标题**：`"PingFang SC", "Microsoft YaHei"` 700/800，字重压满，字间距 `-0.02em`。
- **数字**：等宽 `"SF Mono", "JetBrains Mono", ui-monospace`——速度、圈数、名次都用等宽，跳动时不抖动。
- **不用**第三种字族。窄体斜体那套（参考页的 Barlow Condensed）留到纯拉丁的「SEA BREEZE GP」副标上。

- 顶栏三段左中右对齐，玻璃拟态 `backdrop-filter: blur(14px)`。

## 几何与渲染

- **赛道**：一条程序化闭合曲线（Catmull-Rom 通过 12 个控制点），生成带起伏的路面网格（横向 8 段 × 纵向 240 段），宽度 12 单位。路面法线向上，略微倾斜。
- **边界**：两侧白栏杆（`--sand`）用 `InstancedMesh` 沿曲线每 2 单位放一根柱子 + 顶部连续横条。
- **海面**：赛道外侧一大片平面，用顶点着色器做 Gerstner 简化的正弦叠加，暖金高光 + 深蓝底部。
- **落日**：天空用一个反面渲染的大球体，垂直渐变（顶 `#1b2a4a` → 地平线 `#ffb547`），太阳是一个发光的圆盘 billboard。
- **防风林**：程序化生成的低多边形松树（圆柱树干 + 3 层锥体），`InstancedMesh`，沿赛道两侧按噪声分布，带轻微摇摆。
- **车**：程序化建模的低多边形赛车——楔形车身、四轮、前后尾翼、座舱罩。每台车一个颜色（玩家的用 `--sun`，对手车在 `--sea`/`--danger`/冷灰之间分配）。车轮是绕 X 轴旋转的圆柱，漂移时前轮有明显偏转角。
- **光照**：`HemisphereLight`（天空暖 / 地面暗）+ 一盏 `DirectionalLight` 从落日方向打过来，`ACESFilmicToneMapping`，`outputColorSpace = SRGB`。
- **阴影**：单个 `DirectionalLight` 的 shadow map，2048²，范围只包住玩家车附近（跟随玩家移动 shadow camera），避免全图阴影的性能浪费。

## 玩法

- **三圈**。每圈有计时、圈数、当前名次（按赛道进度百分比实时排名）。
- **漂移**：按住 `空格`（或触屏漂移键）且转向时，车身侧滑角增大，抓地力下降、轮胎冒青绿烟雾、攒氮气。松开后有短暂的「回弹」加速。
- **氮气**：`Shift`（或触屏氮气键）消耗氮气推进，屏幕边缘泛青绿、FOV 从 58° 拉到 72°、速度线粒子。
- **对手 AI**：七台车沿赛道跑，各有基础速度、弯道保守程度和轻微的路线偏好（有人走内线有人走外线），会互相超车但不做碰撞物理。
- **碰撞**：玩家撞到栏杆会被弹回并减速，撞到对手车双方都掉速。
- **结算**：跑完三圈显示名次、单圈最快、总用时、漂移里程、最高速，共享本地存档里的最好成绩。

## 交互

- **桌面**：`W/S` 油门刹车、`A/D` 转向、`空格` 漂移、`Shift` 氮气、`R` 重置、`C` 切镜头、`Esc` 暂停。
- **触屏**：左下方向（左右 + 刹车），右下油门与氮气，漂移键在右下拇指区。竖屏时显示旋转提示。
- **点击交互**：点对手车 → 显示它的车号和当前圈速；点赛道上的路标牌 → 显示剩余圈数。

## 原则

1. **先跑起来再谈好看**：第一屏必须是赛道在动，不是加载条。
2. **一个视觉主张**：落日暖金统领全局，不加第二种强调色。
3. **可读性优先**：HUD 数字用等宽，速度与圈数永远不被 3D 遮挡。
4. **零外部依赖**：three.js 内联，无贴图、无模型文件、无网络请求——所有视觉程序化生成。

## 自审：这套方案是不是「换皮的通用默认」？

对照常见套路逐条检查：

- **黑底 + 霓虹青紫赛博**：不是。底色是落日暖金 + 海青绿，天然属于同一张日落照片。
- **条纹 + 观众席 + 轮胎墙 F1 风**：不做。赛道是海滨公路，边界是白栏杆与防风林。
- **大圆角卡片 + 阴影堆叠**：不用。HUD 是薄玻璃条 + 分段格，不是卡片。
- **「01 / 02 / 03」编号标记**：不用。
- **纯黑渐变背景 + 居中大标题**：标题页有真实的 3D 场景在背后跑，不是纯色底。

结论：视觉主张（落日海滨 + 程序化低多边形）是从主题里长出来的，不是模板换色。保留。
