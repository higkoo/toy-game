# 小偶像の计算器

一款二次元风格的科学计算器，放在 B 站 Toy 里使用。

## 功能

- 四则运算、括号、正负号、百分比
- 三角函数：sin / cos / tan（角度制）
- 对数：ln / log
- 平方根、圆周率 π
- 平方、立方、倒数
- 计算历史：自动保存在浏览器本地，可一键清空
- 表情气泡和粒子反馈，计算时会有小偶像的互动提示

## 操作

点击屏幕按钮输入，`AC` 清空，`←` 删除上一位，`=` 计算结果。展开「历史」可以查看本次保存的计算记录。
