# 小偶像计算器

一款二次元风格的多模式计算器，放在 B 站 Toy 里使用。支持标准计算、科学计算和亲戚称呼三种模式。

## 模式

### 标准计算

- 四则运算
- 百分比、正负号
- 适合日常快速计算

### 科学计算

- 三角函数：sin / cos / tan（角度制）
- 对数：ln / log
- 平方根、圆周率 π
- 平方、立方、倒数
- 括号和常用科学运算

### 亲戚称呼

从「我」开始，按 爸爸、妈妈、哥哥、弟弟、姐姐、妹妹、儿子、女儿、丈夫、妻子 逐级添加关系，实时推算称呼。

- 常见直系：爷爷、奶奶、外公、外婆、孙子、外孙女
- 长辈与平辈：伯父、叔叔、姑妈、舅舅、姨妈、嫂子、姐夫
- 堂表亲：堂兄弟、堂姐妹、表兄弟、表姐妹
- 姻亲：公公、婆婆、岳父、岳母、儿媳、女婿
- 支持「删一步」「重来」和示例关系链
- 关系太绕时会给出友好兜底提示

## 通用功能

- 计算历史保存在浏览器本地，可展开查看或一键清空
- 表情气泡和粒子反馈，计算时会有小偶像的互动提示
- 支持键盘输入：数字、运算符、括号、Enter / `=`、Backspace、Esc

## 操作

点击顶部「标准 / 科学 / 亲戚称呼」切换模式。计算器模式下点击按钮输入，`AC` 清空，`←` 删除上一位，`=` 计算结果。

称呼模式下点击关系按钮逐级添加，点示例可以一键套用常见关系链。
