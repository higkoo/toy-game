# 小偶像围棋

一款放在 B 站 Toy 里的围棋小游戏，支持 9 / 13 / 19 路棋盘，人机、双人和联机都能下。

## 玩法

按围棋规则提子、打劫、停一手（Pass），终局后数子并计算贴目胜负。

- 棋盘：9 路、13 路、19 路
- 难度：简单、普通、困难
- 先手：黑棋

## 模式与功能

- **人机对战**：三档难度的电脑对手
- **双人对战**：同一台设备轮流落子
- **联机对战**：创建房间、浏览房间列表或输入 6 位房间号加入
- **房主审核**：点「加入」后由房主同意或拒绝
- **观战**：房间满员后可以观战
- **悔棋**：联机悔棋需要对方同意
- **换颜色**：房主可以切换黑白先后手
- **好友与在线状态**：显示好友是否在线

## 联机实现

联机没有自建后端，使用公共中转 `ntfy.sh`：

- 房间频道前缀：`bg-go-`
- 发布：`POST https://ntfy.sh/<topic>`
- 接收：优先 SSE 实时订阅，SSE 不可用时自动回退到轮询
- 协议消息：加入申请、同意 / 拒绝、落子、悔棋、全量状态同步、离开房间等
