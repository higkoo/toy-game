# 小偶像围棋

一款放在 B 站 Toy 里的围棋小游戏，支持 9 / 13 / 19 路棋盘，人机、双人和联机都能下。

## 玩法

按围棋规则提子、打劫、停一手（Pass），终局后数子并计算贴目胜负。

- 棋盘：9 路、13 路、19 路
- 难度：简单、普通、困难、大师
- 先手：黑棋

## 模式与功能

- **人机对战**：四档难度的电脑对手，大师会模拟双方后续落子
- **双人对战**：同一台设备轮流落子
- **联机对战**：创建房间、浏览房间列表或输入 6 位房间号加入
- **房主审核**：点「加入」后由房主同意或拒绝
- **观战**：房间满员后可以观战
- **悔棋**：联机悔棋需要对方同意
- **换颜色**：房主可以切换黑白先后手
- **好友与在线状态**：显示好友是否在线

## 联机实现

联机没有自建后端，使用公共中转 `ntfy.sh`：

- 房间频道前缀：`bg-go-`
- 发布：`POST https://ntfy.sh/<topic>`
- 接收：优先 SSE 实时订阅，SSE 不可用时自动回退到轮询
- 协议消息：加入申请、同意 / 拒绝、落子、悔棋、全量状态同步、离开房间等

## 榜单

接 TOY 原生排行榜（`board: 1`），并在页面内自带排行榜面板（右下角「榜单」入口）。

- **平台规则**：`submitScore` 传绝对分，服务端只保留该榜位的历史最高分，本次更低不覆盖；`getRankList` 游客可读，`getMyRank` 需登录。
- **榜单积分（写进平台榜，只增不减）**：赢按难度阶梯加 1 / 2 / 3 / 4 分，输和平局不加；每玩过一局至少 1 分，所以「只要玩过，榜单上就有记录」。
- **净胜分（只在本页显示，可负）**：赢 +阶梯分、输 -阶梯分、平 0，一直累计。平台榜不支持分数下降，负分值放在这里呈现。
- 教学关与联机观战不计分；双人同屏只记参与。联机沿用当前难度档位作为阶梯。
- 面板只在点开时拉一次并本地缓存，不轮询；带加载中 / 空态 / 失败重试；非 Toy 容器显示本地积分并提示去 B站 App 查看。
- 累计分存 `localStorage`；换设备或清缓存后，面板会用 `getMyRank` 返回的历史最高分校准「榜单积分」，净胜分是本地数据会重置。
