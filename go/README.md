# 小偶像围棋

一款放在 B 站 Toy 里的围棋小游戏，支持 9 / 13 / 19 路棋盘，人机、双人和联机都能下。

## 玩法

按围棋规则提子、打劫、停一手（Pass），终局后数子并计算贴目胜负。

- 棋盘：9 路、13 路、19 路
- 难度：简单、普通、困难、大师
- 先手：黑棋

## 模式与功能

- **人机对战**：四档难度的电脑对手，大师会模拟双方后续落子
- **双人对战**：同一台设备轮流落子
- **联机对战**：创建房间、浏览房间列表或输入 6 位房间号加入
- **房主审核**：点「加入」后由房主同意或拒绝
- **观战**：房间满员后可以观战
- **悔棋**：联机悔棋需要对方同意
- **换颜色**：房主可以切换黑白先后手
- **好友与在线状态**：显示好友是否在线

## 联机实现

联机没有自建后端，使用公共中转 `ntfy.sh`：

- 房间频道前缀：`bg-go-`
- 发布：`POST https://ntfy.sh/<topic>`
- 接收：优先 SSE 实时订阅，SSE 不可用时自动回退到轮询
- 协议消息：加入申请、同意 / 拒绝、落子、悔棋、全量状态同步、离开房间等

## 榜单

接 TOY 原生排行榜（`toy.submitScore`），统一用 1 号榜（`board: 1`）。

- 分值阶梯：简单 1 / 普通 2 / 困难 3 / 大师 4。
- 赢一局加对应分值，输一局扣同样分值，平局 0 分。
- 每局结算都会上报一次累计分，页面打开时也会上报一次当前值，所以**只要玩过，榜单上就有记录**。
- 教学关与联机观战不计分；双人同屏只记参与（0 分，仍上报）。
- 累计分存 `localStorage`；`submitScore` 传的是**绝对值**，不是增量。

> 平台榜若采用「取历史最高分」语义，输分导致的下降可能不会体现在榜单排序上；
> 代码每次都会重新提交最新绝对值，页面侧不做额外补偿。
> 榜单结果由 TOY 平台原生榜单承载，页面内未新增榜单 UI，避免挤占移动端界面。
