# 小偶像五子棋

一款放在 B 站 Toy 里的五子棋小游戏，支持 9 / 13 / 15 路棋盘，单机、双人和联机都能玩。

## 玩法

黑棋先手，双方轮流落子，先连成五子（横、竖、斜均可）的一方获胜。

- 棋子颜色：黑棋 / 白棋
- 棋盘：9 路、13 路、15 路
- 难度：简单、普通、困难

## 模式与功能

- **人机对战**：三档难度的电脑对手
- **双人对战**：同一台设备轮流落子
- **联机对战**：创建房间或从房间列表加入，房主同意后上桌
- **教学模式**：带让子、提示和课堂讲解的入门流程
- **回放**：查看最近的对局
- **房间大厅**：浏览当前存在的房间，点「加入」向房主发出申请，也可以直接输入 6 位房间号
- **好友与在线状态**：显示好友是否在线，可从房间直接邀请
- **观战**：房间满员后可以观战
- **悔棋**：联机悔棋需要对方同意
- **换颜色**：房主可以切换先后手

## 联机实现

联机没有自建后端，使用公共中转 `ntfy.sh`：

- 房间频道前缀：`bg-gomoku-`
- 发布：`POST https://ntfy.sh/<topic>`
- 接收：优先 SSE 实时订阅，SSE 不可用时自动回退到 NDJSON 轮询
- 协议消息：`hi`（申请加入）、`ok` / `no`（同意 / 拒绝）、`mv`（落子）、`st`（全量状态）、`undo` / `undo-ok` / `undo-no`、`bye` 等

弱网处理（v24）：

- 请求带超时，避免半开连接一直挂起
- 发布失败自动重试，并用消息 ID 去重，防止重复落子
- 轮询失败按 1.5s → 3s → 6s 退避，成功后恢复
- 20 秒收不到房间消息自动重建连接
- 断网 / 恢复网络自动处理
- 房间栏提供手动「重连」按钮，并主动同步一次完整棋局
- 连续失败时在房间信息中提示「网络慢，可点重连」

体验修复（v25）：

- 大厅弹窗 max-height 添加 dvh 兜底，小手机不再被遮住
- 好友心跳/轮询从 30s 缩短到 12s，在线判断从 180s 降到 90s
- 大厅心跳从 6s 加快到 3s，轮询窗口从 45s 放宽到 90s
- 离开房间时清理拒绝列表，修复被拒绝者进不了新房的问题
