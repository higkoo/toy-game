# 倪海厦学习天地

一个放在 B 站 Toy 里的中医学习资源导航页，整理倪海厦先生「天纪、人纪、地纪」相关课程视频与讲义。原附的全文知识库已于 v1.25 移除（内容迁移至独立项目《岐黄典籍故事》，slug `qihuang`）。

## 内容结构

### 天纪

- 天机道
- 人间道
- 地脉道

- 针灸
- 黄帝内经
- 神农本草经
- 伤寒论
- 金匮要略
- 仲景心法
- 医案

### 地纪

- 地纪 · 未竟之章

### 知识库

已于 v1.25 移除。原先附加的《倪海厦全集》核心内容知识库（含症状、方剂、剂量、穴位主治、药材功效等诊疗内容）被审核判定为「违法违规、其他」而反复驳回，对照实验证实违规源即知识库条目本身。相关目录 `src/kb/` 与首页入口已整体删除；内容迁移至独立项目《岐黄典籍故事 · 中医文化合集》（slug `qihuang`），改写为零诊疗的文化读物。

每张课程卡片都提供「观看」和「讲义」入口：「观看」在 App 内打开 B 站视频列表，「讲义」不直接跳转——点击弹出链接面板，手动复制后粘贴到浏览器访问（Toy 内禁止直接跳转外部链接）。

## App 内视频跳转

页面接入了 B 站 Toy SDK：

- 点击课程视频卡片时调用 `toy.navigate({ type: 'video', id: BV号 })`，在 App 内打开对应视频
- 必须在真实点击手势内同步调用
- SDK 不可用或调用失败时，弹出兜底面板，提供复制视频链接

## 榜单

接 TOY 原生排行榜（`board: 1`），页面内自带排行榜面板。**入口就是右下角的版本号**——点它打开榜单，页脚不再单独显示「排行榜」链接。

- **入口**：右下角版本号是原生 `<button>`，鼠标点击或键盘 Enter / Space 都能打开，`:focus-visible` 有焦点圈；`title` 写明「点开排行榜」。
- **平台规则**：`submitScore` 传绝对分，服务端只保留历史最高分；`getRankList` 游客可读，`getMyRank` 需登录。
- **每看一集 +1**，一直累计；同一集只计一次（按 BV 号去重），重复点开不刷分。
- 「看一集」以点击打开该集为准（Toy 内走 SDK 原生导航，PC 端跳 B站视频页）；只看页面、不点开任何一集不计分。
- 已看集数与累计分存 `localStorage`；换设备或清缓存后，面板会用 `getMyRank` 返回的历史最高分校准榜单积分显示。
- 面板只在点开时拉一次并本地缓存，不轮询；带加载中 / 空态 / 失败重试；非 Toy 容器提示去 B站 App 内打开。
