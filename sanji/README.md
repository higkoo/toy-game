# 倪海厦学习天地

一个放在 B 站 Toy 里的中医学习资源导航页，整理倪海厦先生「天纪、人纪、地纪」相关课程视频与讲义。

## 内容结构

### 天纪

- 天机道
- 人间道
- 地脉道

### 人纪

- 针灸
- 黄帝内经
- 神农本草经
- 伤寒论
- 金匮要略
- 仲景心法
- 医案

### 地纪

- 地纪 · 未竟之章

每张课程卡片都提供「观看」和「讲义」入口，分别跳转到 B 站视频列表和金山文档。

## App 内视频跳转

页面接入了 B 站 Toy SDK：

- 点击课程视频卡片时调用 `toy.navigate({ type: 'video', id: BV号 })`，在 App 内打开对应视频
- 必须在真实点击手势内同步调用
- SDK 不可用或调用失败时，弹出兜底面板，提供复制视频链接

## 目录结构

```text
sanji/
├── src/
│   ├── index.html        # 页面源码
│   └── img/              # 图片素材
│       ├── cover-*.jpg   # 7 张课程封面（天纪/针灸/内经/本草/伤寒/金匮/仲景）
│       ├── diji-vista.jpg  # 地纪残章卡片背景
│       ├── hero-portrait.jpg  # 首屏倪海厦人像
│       ├── icon.png      # Toy 图标（1024×1024）
│       └── poster.jpg    # Toy 海报（1280×720）
└── README.md
```

页面图片放在 `src/img/`，HTML 里用相对路径 `img/xxx.jpg` 引用；`toy update` 打包 `src/` 时整体上传到 CDN。装饰性视觉元素（渐变、纹样）仍由 CSS 与内联 SVG 完成。

## 榜单

接 TOY 原生排行榜（`board: 1`），并在页面内自带排行榜面板（页面内「排行榜」入口）。

- **平台规则**：`submitScore` 传绝对分，服务端只保留历史最高分；`getRankList` 游客可读，`getMyRank` 需登录。
- **每看一集 +1**，一直累计；同一集只计一次（按 BV 号去重），重复点开不刷分。
- 「看一集」以点击打开该集为准（Toy 内走 SDK 原生导航，PC 端跳 B站视频页）；只看页面、不点开任何一集不计分。
- 已看集数与累计分存 `localStorage`；换设备或清缓存后，面板会用 `getMyRank` 返回的历史最高分校准榜单积分显示。
- 面板只在点开时拉一次并本地缓存，不轮询；带加载中 / 空态 / 失败重试；非 Toy 容器提示去 B站 App 内打开。
