# 倪海厦学习天地

一个放在 B 站 Toy 里的中医学习资源导航页，整理倪海厦先生「天纪、人纪、地纪」相关课程视频与讲义。

## 内容结构

### 天纪

- 天机道
- 人间道
- 地脉道

### 人纪

- 针灸
- 黄帝内经
- 神农本草经
- 伤寒论
- 金匮要略
- 仲景心法
- 医案

### 地纪

- 地纪 · 未竟之章

每张课程卡片都提供「观看」和「讲义」入口，分别跳转到 B 站视频列表和金山文档。

## App 内视频跳转

页面接入了 B 站 Toy SDK：

- 点击课程视频卡片时调用 `toy.navigate({ type: 'video', id: BV号 })`，在 App 内打开对应视频
- 必须在真实点击手势内同步调用
- SDK 不可用或调用失败时，弹出兜底面板，提供复制视频链接

## 目录结构

```text
sanji/
├── src/
│   ├── index.html        # 页面源码
│   └── img/              # 图片素材
│       ├── cover-*.jpg   # 7 张课程封面（天纪/针灸/内经/本草/伤寒/金匮/仲景）
│       ├── diji-vista.jpg  # 地纪残章卡片背景
│       ├── hero-portrait.jpg  # 首屏倪海厦人像
│       ├── icon.png      # Toy 图标（1024×1024）
│       └── poster.jpg    # Toy 海报（1280×720）
└── README.md
```

页面图片放在 `src/img/`，HTML 里用相对路径 `img/xxx.jpg` 引用；`toy update` 打包 `src/` 时整体上传到 CDN。装饰性视觉元素（渐变、纹样）仍由 CSS 与内联 SVG 完成。

## 榜单

接 TOY 原生排行榜（`toy.submitScore`），统一用 1 号榜（`board: 1`）。

- 每打开一次页面计 1 分，累计不清零（"看过一次，计 1 分，一直累计"）。
- 15 秒内重复打开不重复计分，避免刷新刷分。
- 累计分存 `localStorage`；`submitScore` 传的是**绝对值**，不是增量。
- SDK 在本页异步就绪，模块会轮询等待；非 TOY 容器静默跳过。

> 榜单结果由 TOY 平台原生榜单承载，页面内未新增榜单 UI，避免挤占移动端界面。
