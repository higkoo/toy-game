# HyperFrames 可执行逐帧描述

> 面向 Step 4/5 的接线说明。**本文件是规格，不是已搭建的 composition**——`compositions/` 目录尚未创建。
> 每帧给出：主体 / 画面 / 镜头运动 / 字幕出现方式 / 动效参数 / `data-*` 接线 / 素材来源 / 事实标注。

## 1. 全局接线约定（HyperFrames core）

### 1.1 根与时长

```html
<div data-composition-id="sanji-60s" data-width="1920" data-height="1080" data-duration="60">
```

- 根用 `width/height: 100%`，**不硬编码 1920px/1080px**；画布尺寸由 `data-width`/`data-height` 决定。
- 全片注册**恰好一个** `gsap.timeline({paused:true})` 到 `window.__timelines["sanji-60s"]`，key 必须等于 `data-composition-id`。
- 渲染长度取根 `data-duration`（60s），不是 timeline 长度。

### 1.2 轨道分配（`data-track-index` 只是 Studio 显示 lane，不约束时序）

| Track | 内容 | clip 数 | 说明 |
|---|---|---|---|
| T0 | 宣纸背景 + 颗粒 + 双层山水 | 1（0–60s） | 跨帧连续，避免每场背景闪动 |
| T1 | 主画面（UI plate / 信息图） | 17 | 每帧一个 `class="clip" data-start/data-duration` |
| T2 | 高亮 / 词卡 / 路径线 / 光晕 | 按需 | 跟随对应帧，或与主画面同 clip 内分层 |
| T3 | 字幕层 | 1 底板（0–60s）+ 18 句文字 | 底板常驻，文字按句定时 |
| T4 | 音频 | BGM 1 + VO 18 | `<audio>` 必须带 `id`，不加 `crossorigin` |

### 1.3 确定性红线（`hyperframes-core` / `determinism-rules`）

- 禁用 render-time 时钟、`Math.random()`、网络请求、输入状态；所有「随机散落」用**预计算坐标表**写死。
- **不 tween `.clip` 的 `visibility` / `autoAlpha` / `display`**（lint: `gsap_animates_clip_element`）；淡入淡出作用在 clip **内部的 wrapper** 上，clip 可见性由框架管理。
- 居中用 flex / `inset`，不用 `transform: translate(-50%,-50%)` 后再 GSAP `x`/`y`（lint: `gsap_css_transform_conflict`）；位移用 `fromTo` 或 `xPercent/yPercent`。
- 所有 `id` 全页唯一（子合成加前缀 `sanji-60s-`）。
- 字体用随项目附带的本地 `@font-face`（`Noto Serif CJK SC` / 思源宋体），否则 lint 报 `font_family_without_font_face`。
- `<video>`/`audio` 不加 `crossorigin`；`<video data-start>` 不能嵌在另一个带 `data-start` 的普通元素里。

### 1.4 字幕层规范

- **底板常驻**：宣纸半透明条（`rgba(253,250,242,.88)`）+ 上下 1px 金线 + 左右短金线，宽 1460px 居中，底部 `padding-bottom: 52px`，高 ≥74px。开场 0–1.4s 与收尾 59.2–60s 整体淡入/淡出。
- **文字切换不闪空**：相邻两句严格接续（前句 `to` = 后句 `from`）；新句立即以 **60% 不透明**出现、7 帧内淡到全亮，**不做淡出**（避免「底板在、文字空」的空白条）。
- **关键词金墨高亮**：如「一页」「顺序」「一眼」「不丢线」用 `#a3803f`。
- 单句 ≤20 字，`fontSize: 35px`，`whiteSpace: nowrap`，不折行；最长 14 字，1460px 底板内安全。
- 字幕时间轴以 `SCRIPT.md` 的 18 句窗口为初始值，**最终以 TTS 词级时间戳替换**。

### 1.5 镜头运动词表（全部作用在 inner wrapper，不动画 clip 本身）

| 术语 | 实现 | 典型参数 |
|---|---|---|
| `push-in` 推近 | wrapper `scale` 1.0→1.35，可选 `transform-origin` 指向兴趣点 | 18–24 帧，`power2.out` |
| `pull-back` 拉远 | wrapper `scale` 1.2→1.0 | 20 帧，`power2.inOut` |
| `pan` 平移 | wrapper `x` 位移（预计算 px） | 线性或 `power1.inOut` |
| `gather` 收拢 | 多个子元素 `fromTo` 到网格坐标 | 24 帧，`power3.out`，错峰 3 帧 |
| `cut` / `crossfade` / `wipe` | clip 边界 + 内部 opacity / mask | 8–13 帧 |
| `parallax` | 背景层与主层不同速率位移（≤8px） | 确定性关键帧 |

### 1.6 素材与缺口

- **已提供**：11 张产品图片（路径见 `BRIEF.md`）、本地 `index.html` 源码。
- **未提供**：产品 UI 录屏 / 逐屏截图。`visual_type: ui-capture` 的 5 帧（F05 / F11 / F12 / F13 / F17）待采集。
- **降级方案**（符合 `product-launch-video` Step 1 规则）：以本地 `index.html` 渲染的**静态截图为底版（plate）**，只重建会动的那个组件（分集面板、高亮入口、收藏星标），**不凭空重建整站**；长滚动镜头用 `full-page.png` 1x 底板做 viewport 位移，推近超过 1:1 需单独 2x 局部截图。
- 概念图解帧（F01–F04 / F06–F10 / F14–F16 中的图谱、词卡、进度条）用 HTML/CSS/SVG 确定性绘制，**不冒充产品 UI**；F13 的概念词卡须加虚线边框 +「示意」角标与真实 UI 明确区分。

## 3. 逐帧详述

### F01 · Hook（0–3s / `data-start="0" data-duration="3"`）

- **主体**：12 张半透明「资料卡」（视频缩略 / PDF / 链接 / 笔记碎片），中央大字「越学越散？」
- **画面**：卡片从四角按**预计算坐标表**漂入并互相遮挡；1.6s 全部定格，大字金墨重击落下，卡片降到 15% 不透明度并去饱和。
- **镜头运动**：无整体位移；卡片各自 `fromTo` 位移，错峰 2 帧，`power3.out`，24 帧完成。
- **字幕出现方式**：**S1 重击落下**——「倪师资料铺天盖地，越学越散？」整句在 1.6s 从 1.3× 缩到 1.0× 并淡入（10 帧），不进底部常驻条；2.9s 起底部条淡入接管。
- **素材**：无产品图片；纯 SVG/CSS。
- **实现要点**：无音乐（BGM 静音）；不得使用人像素材；不得用 `Math.random()` 生成散落坐标。

### F02 · Pain 分散（3–6s / `3` / `3`）

- **主体**：4–5 个窗口轮廓 + 版本标签（480i / 720p / 1080p / 无删减 / 删减版）。
- **画面**：窗口错位漂浮，标签逐个闪现又互相覆盖，制造「很多但没有一个是对的」。
- **镜头运动**：整体 `parallax` 漂移 ≤8px，确定性关键帧（非随机）。
- **字幕出现方式**：S2 底部常驻条，句首立即 60% → 7 帧全亮，「版本还乱」四字金墨高亮。
- **实现要点**：与 F01 用 `crossfade`（10 帧）衔接；窗口降饱和到 40% 以免抢字幕。

### F03 · Pain 遗忘（6–8.5s / `6` / `2.5`）

- **主体**：横向进度条 + 5 个节点。
- **画面**：填充从 0 走到 80%，随后**倒退**到 35%，已完成节点逐个变灰、边缘虚化。
- **镜头运动**：固定；只动画填充宽度与节点颜色。
- **字幕出现方式**：S2；「忘了前面」金墨高亮。
- **事实标注**：进度条为**概念图解**，产品无学习进度功能；画面不得出现「我的进度」等产品化字样。

### F04 · Pain 查讲脱节（8.5–11s / `8.5` / `2.5`）

- **主体**：左侧搜索框（输入「合谷」）+ 空转结果区，右侧讲义文档窗口，中间断裂虚线。
- **画面**：框内逐字打字机（12 帧），结果区转圈无结果；右侧窗口被推远并压暗。
- **镜头运动**：右窗 `scale` 1.0→0.82 + `x` 右移 120px（16 帧）。
- **字幕出现方式**：S2；框内打字机与字幕互不干扰。
- **事实标注**：**概念图解**。源码无搜索框、无穴位/方剂检索；此帧只表达痛点，不宣称产品能力。建议画面角落加极小「痛点示意」字样。右侧讲义窗口的条目名用源码真实措辞（《针灸》读书笔记 / 《黄帝内经》读书笔记），不写「针灸大成」「辑录」等非源码用词。

### F05 · Solution 一页收齐（11–15s / `11` / `4`）

- **主体**：产品首页真实截图（宣纸底 + 三大体系数据条 + 课程卡）。
- **画面**：把 F01 的散卡从四周吸附、缩放、整齐落位到「天纪 / 人纪 / 地纪」三栏；背景提亮，情绪转折。
- **镜头运动**：`gather`（24 帧，`power3.out`，错峰 3 帧）+ 整体 `scale` 1.15→1.0 回正（20 帧）。
- **字幕出现方式**：S2；「一页」金墨高亮；`wipe` 转场 12 帧。
- **素材**：首页截图（待采集）；`cover-tianji.jpg` 等封面缩略。
- **实现要点**：**真实 UI 为底版**，只重建「散卡吸附」这一个动效层；不得重建整站。截图缺失时按 §1.6 降级。
